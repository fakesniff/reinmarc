# Claude project instructions
Claude is de hoofd-agent/projectleider. De gebruiker is geen programmeur; leg belangrijke keuzes eenvoudig in het Nederlands uit.
Gebruik Codex als tweede programmeur/reviewer voor serieus programmeerwerk.
Werk standaard zo: bekijk eerst het project, controleer Git, maak een kort plan, laat Codex waar nuttig reviewen/implementeren, controleer zelf de wijzigingen en test.
Wijzigt een taak zichtbare gebruikersoutput (UI, styling, copy, publieke docs)? Voer na de functionele implementatie een Humanizer-pass uit volgens HUMANIZER.md en test daarna opnieuw.
Geen commit, push, merge, force-push of destructieve actie zonder expliciete toestemming.
Nooit secrets, API keys, tokens of .env-bestanden committen.
